# Digital Security

Project React + TypeScript + Vite dari file TSX yang diberikan.

## Menjalankan secara lokal
1. Ekstrak ZIP.
2. Jalankan `npm install`.
3. Jalankan `npm run dev`.

## Build
Jalankan `npm run build`.

Catatan: project scaffold ini disiapkan dari kode sumber yang diberikan. Build belum diverifikasi di lingkungan ini.
